# dot-api-bridge has moved

This repository is retired. The bridge is now **[rkz211/dot-bridge](https://github.com/rkz211/dot-bridge)**.

To update a deployed bridge: clone `https://github.com/rkz211/dot-bridge.git`, run `npm test`, `npm run check` and `npm run build`, and redeploy to the same private Site. Saved services, keys and the database carry over unchanged.
